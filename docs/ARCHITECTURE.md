## 2. Security Boundaries & Guardrails

1. **Context Isolation**: `contextIsolation: true` and `nodeIntegration: false` prevent renderer code from touching Node.js APIs directly.
2. **IPC Whitelisting**: Strict, namespaced IPC channels (`window`, `app`, `fs`, `terminal`, `ai`, `agent`, `git`, `db`).
3. **Workspace Boundary Enforcement**: `is_within_directory` blocks any read/write access attempting path traversal (`../`) outside the active project.
4. **Secret Filtering**: `.env`, `.pem`, `.key`, `id_rsa`, `credentials.json` are automatically excluded from directory scans and LLM prompts.
5. **Human-in-the-Loop Approvals**:
   - File edits generated by the Autonomous Agent require explicit button approval.
   - Terminal commands proposed by the Agent require explicit approval.
   - Remote Git pushes require explicit confirmation.
   - Every file change is saved with original content for one-click Undo/Rollback.
