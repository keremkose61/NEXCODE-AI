# NEXCODE AI – Keyboard Shortcuts Cheat Sheet

| Shortcut | Scope | Description |
|---|---|---|
| `Ctrl+K` | Editor / Global | Open **Inline AI Bar** (Code generation, refactoring, fixing) |
| `Ctrl+L` | Global | Toggle **AI Assistant & Agent** Right Panel |
| `Ctrl+B` | Global | Toggle **Left Sidebar** (Explorer, Search, Git, Extensions) |
| `Ctrl+J` | Global | Toggle **Bottom Panel** (Terminal, Debug Console, Problems) |
| `Ctrl+P` | Global | **Quick Open** File Search |
| `Ctrl+Shift+P` / `F1` | Global | **Command Palette** |
| `Ctrl+,` | Global | Open **Settings Modal** |
| `Ctrl+S` | Editor | Save active document |
| `Ctrl+H` | Editor | Find and Replace |
| `Shift+Alt+F` | Editor | Format Document |
| `F5` | Editor / Debugger | Start Debugging or Continue execution |
| `F10` | Debugger | Step Over next line |
| `F11` | Debugger | Step Into function call |
| `Shift+F11` | Debugger | Step Out to caller |
| `Shift+F5` | Debugger | Stop Debugging session |
| `F9` | Editor | Toggle Breakpoint on current line |
| `Esc` | Modals | Close active modal, palette, or Inline AI bar |
